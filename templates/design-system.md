# <Project name> — design system

The lasting record of how this product looks and behaves on screen. Every run that touches a screen reads it and follows it; the designer extends it, and a redesign is the only thing that replaces it. Keep it under 200 lines. A value written here is a choice the project made: a reviewer or a cleanup treats it as intended.
